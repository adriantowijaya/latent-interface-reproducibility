## Description
Version 1.1.0 preserves the original v1.0.0 data, code, frozen configurations, machine-readable results, checkpoint manifests, and checkpoint archives, and adds the post hoc zero-training analyses used by the Knowledge-Based Systems retargeted manuscript. The extension contains deterministic 96/72/48 alignment-panel sensitivity, GRU/Transformer receiving-context evidence, paired FUNCTIONAL-minus-THETA-RKA country comparisons, estimator-harmonized Level-3 evidence, integrity/freeze reports, and a manuscript-to-artifact reproducibility map. No model training, checkpoint modification, outcome-based series replacement, or threshold tuning was performed for the extension.
